1. Start MongoDB locally (mongod or Docker: docker run -d -p 27017:27017 mongo)
2. Fill in OAuth keys in Backend/.env:
   - Google: console.cloud.google.com (https://console.cloud.google.com) → OAuth 2.0 Client IDs
   - GitHub: Settings → Developer settings → OAuth Apps → New
   - Set callback URLs to http://localhost:3000/auth/google/callback and /auth/github/callback
3. Start backend: cd Backend && npm run dev
4. Start frontend: cd Frontend && npm run dev
